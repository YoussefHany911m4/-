# Third-party assets and dependencies

- Runtime: plain HTML, CSS and vanilla JavaScript. No third-party scripts, SDKs, analytics, maps, embeds, CDNs, or runtime libraries are included.
- Fonts: supplied assets did not include WOFF2 files. The current build uses system font stacks and Georgia/Arial/Tahoma fallbacks. Self-host licensed Playfair Display, Montserrat and Cairo WOFF2 files with their SIL Open Font License texts before launch to satisfy the requested typography.
- Build: Node.js built-ins plus Python standard library. No npm runtime dependencies. Pillow was used only to create optimized local JPEG copies during preparation and is not required to serve the site.
- Logo: supplied artwork copied unchanged. No Internet imagery, social feeds, analytics, or third-party embeds are used.
